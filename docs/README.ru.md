# Triki Adventure — на русском

[English](../README.md) · [Українська](README.uk.md) · [Polski](README.pl.md) · **Русский**

**Triki Adventure** — экспериментальная игра для iPhone, в которой физическая Bluetooth-фигурка Żabka Triki используется как контроллер движений. Это независимый проект, не связанный официально с Żabka.

## Что уже проверено
- Подключение к Triki через BLE на Mac.
- Получение данных гироскопа и акселерометра.
- Сборка приложения SwiftUI в Xcode и установка на iPhone.
- Управление игрой по BLE на iPhone ещё требует проверки.

## Этапы разработки
1. Загрузить исходный проект Xcode.
2. Наладить BLE-подключение на iPhone.
3. Добавить калибровку, жесты и сенсорное управление.
4. Сделать первый полноценный игровой уровень.
5. Добавить уровни, противников и сохранение прогресса.
6. Протестировать и подготовить выпуск.

## Делайте свои проекты с Triki
На основе [экспериментального примера кода](../examples/README.md) и [документации BLE-протокола](BLE_PROTOCOL.md) можно создавать собственные игры, контроллеры жестов и образовательные прототипы.
